# Fixly

Fixly is a Python-based AI-powered repair guidance web app. Users describe a problem, upload photos, and receive structured repair advice generated by a multi-model AI pipeline.

---

## Project Status

### Phase 1 : Foundation 
- FastAPI backend created
- NiceGUI frontend created
- backend and frontend confirmed running locally

### Phase 2 : Router and Backend Structure 
- backend routes reorganised into `app/api/`
- central router added via `app/router.py`
- scalable, modular backend architecture established

### Phase 3 : Database Foundation 
- SQLAlchemy 2.0 integrated with full async support
- async PostgreSQL driver (`asyncpg`) configured
- full schema models created (`users`, `user_tokens`, `sessions`, `uploads`, `analyses`, `messages`)

### Phase 4 : Docker and Alembic 
- PostgreSQL containerised with Docker Compose
- Alembic configured for async SQLAlchemy migrations

### Phase 5 : Authentication System 
- register, login, and logout endpoints completed
- bearer token authentication implemented end-to-end
- password hashing with `passlib` + `bcrypt`
- `User` and `UserToken` models and database logic stabilised
- email normalisation (lowercase, trimmed) enforced at the schema level
- `plan` column defaults to `"free"` at both the Python and PostgreSQL level
- async SQLAlchemy post-commit ORM state handled correctly (`db.refresh`)
- authentication-related 500 errors fixed; wrong credentials return clean 401
- authentication frontend UI built in NiceGUI:
  - register page with validation
  - login page with error handling
  - authenticated user session stored via `app.storage.user`
  - header shows username and logout button when logged in
  - logout clears session and revokes token server-side
  - landing page shows personalised greeting and dashboard entry point

## Database Schema

| Table | Purpose |
|---|---|
| `users` | registered user accounts |
| `user_tokens` | active bearer tokens (one per login session) |
| `sessions` | repair sessions (anonymous or authenticated) |
| `uploads` | image and file uploads attached to a session |
| `analyses` | AI pipeline results for a session |
| `messages` | conversation messages within a session |

## Run Locally

### Prerequisites
- Python 3.11+
- Docker Desktop running

### 1. Start PostgreSQL

From the project root:

```bash
docker compose up -d db
```

### 2. Apply migrations

```bash
cd backend
.\.venv\Scripts\Activate.ps1
alembic upgrade head
```

### 3. Start the backend

```bash
uvicorn main:app --host 127.0.0.1 --port 8080 --reload
```

### 4. Start the frontend

Open a second terminal:

```bash
cd frontend
.\.venv\Scripts\Activate.ps1
python main.py
```
